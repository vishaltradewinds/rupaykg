# Urban and Rural Operating Model

## Urban
```text
Generator -> Segregation -> Collection -> Ward/ULB -> Transfer/MRF -> Processor -> MRV -> Compliance/Value -> Registry -> Settlement -> Reporting
```

## Rural
```text
Household/Farmer/SHG -> Village aggregation -> Gram Panchayat/Cluster -> Collection/Transport -> Local or regional processor -> MRV -> Compliance/Value -> Registry -> Settlement -> Reporting
```

Both workflows use the same core concepts: activity, material batch, measurement, custody event, evidence, verification, methodology, credential, obligation, registry event and settlement.

The rural model must tolerate intermittent connectivity, delayed synchronization, shared devices, local aggregation and lower infrastructure density. The urban model must support higher event volume, route operations, ward-level visibility and municipal integrations.

The distinction is operational, not a separate product or database model.
